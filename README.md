# 09 배열 실습

- test01.c: 다섯 학생의 점수 10, 20, 30, 40, 50 저장 및 출력
- test02-1.c: 다섯 점수 입력 후 배열 출력
- test02-2.c: 점수 평균 계산 (10, 20, 30, 40, 50 입력 시 30)
- test03-1.c: 난수 배열 grade를 score에 원소별 복사
- test03-2.c: 배열 비교, 다른 값의 인덱스 출력
- test04.c: 함수로 배열 원소 제곱 (1, 2, 3, 4 -> 1, 4, 9, 16)
- test05.c: addMatrix와 printMatrix로 3x3 행렬 덧셈 및 출력

실습 5 결과:

```text
  3  3  0
  8 10  1
  7  0  6
```

각 C 파일은 독립적으로 실행한다. GCC가 있는 환경에서 `gcc test01.c -o test01.exe`처럼 빌드하거나 GNU make가 있으면 `make`로 전체 빌드한다.
